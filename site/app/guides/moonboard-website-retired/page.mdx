# The MoonBoard website is retired — where to browse problems now

<p className="mt-2 text-sm text-[var(--muted)]">Last updated: July 25, 2026</p>

You can no longer browse MoonBoard problems on moonboard.com — the problem pages
now sit behind a security challenge and return errors. Moon Climbing has moved
everything into the official MoonBoard mobile app. To browse problems in a web
browser today, the community-built options are [Boardhang](https://www.boardhang.app),
Boardsesh, and MoonBoard Guidebook.

## What happened to moonboard.com?

For years, moonboard.com let anyone open a problem page (the
moonboard.com/Problems/View/… URLs) in a browser. Those pages are no longer
reachable: they sit behind a security challenge and return errors, even though
thousands of them are still listed in Google. If you arrived here from one of
those dead search results, that is why.

This is not an outage. Moon Climbing's stated direction is that everything —
browsing, logging, benchmarks — lives in the MoonBoard mobile app. The
website's remaining stated purpose is account login and board management.
Problem browsing on the open web is effectively gone from the official side.

## Where can I browse MoonBoard problems now?

Four realistic options. Full disclosure before the list: we build Boardhang, so
we are biased — here is the honest comparison anyway.

### 1. Boardhang — free, in the browser, no account

[Boardhang](https://www.boardhang.app) is a curated MoonBoard catalog that runs
in any browser: roughly 12,000 problems (benchmarks plus problems with 10 or
more repeats), including 2,832 official benchmarks, across MoonBoard 2016,
MoonBoard 2024, Masters 2017, Masters 2019 and Mini 2025. You get filters,
search, favorites and a logbook without installing anything or creating an
account, and if you have a DIY LED board it can light problems directly over
Web Bluetooth.

The honest limits: it is a curated subset, not every problem ever set; the data
is community-mirrored; and it is unofficial, with no affiliation to Moon
Climbing.

### 2. The official MoonBoard app — complete, but app-only

The MoonBoard app is the only sanctioned, complete source of problems. If you
want every problem, official benchmark updates and an official logbook, this is
it. The trade-off is that it requires installing the app and signing in with a
Moon account, and there is no way to browse from a web browser or share a
problem as a normal web link.

### 3. Boardsesh — multi-board community project

[Boardsesh](https://www.boardsesh.com) is a community web and app project that
covers Kilter, Tension and MoonBoard. Its public data mirror is the foundation
many community tools — including Boardhang — build on. A good pick if you
climb on several board brands and want one tool for all of them.

### 4. MoonBoard Guidebook — benchmarks only

[MoonBoard Guidebook](https://moonboard.simonchase.com) is a community
benchmark browser. It is benchmarks-only, and its data snapshot is a couple of
years old — fine for working through a classic tick list, less useful for
anything recent.

## What happened to my favorites?

On June 22, 2026, Moon Climbing rolled out an app migration that required a
full uninstall and reinstall of the MoonBoard app. Favorites that were stored
only locally on the device did not survive that step, and many climbers opened
the new app to find years of saved problems gone. Moon also scheduled the old
app and its API to stop working about six weeks after the migration finished
rolling out, so staying on the old version is not a way out.

There is no undo for locally stored favorites lost in the reinstall. If you are
rebuilding a list from memory, browsing by grade and benchmark status in a
catalog like Boardhang or the official app is the fastest way to find the
problems you remember. It is also a good argument for keeping your ticks
somewhere that survives an app migration — an account-synced logbook, an
export, even a spreadsheet.

## Which option should I use?

- **You want every problem and an official logbook:** use the official
  MoonBoard app. Nothing else is complete or sanctioned.
- **You want to browse quickly in a browser, share problems as links, or look
  things up without an account:** use Boardhang.
- **You climb on Kilter or Tension too:** use Boardsesh and get all your boards
  in one place.
- **You just want the classic benchmark tick list:** MoonBoard Guidebook still
  does that fine.

These are not exclusive — plenty of climbers browse and share in a web catalog
and log official ascents in the app.
